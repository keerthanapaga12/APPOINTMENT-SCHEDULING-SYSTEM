About Our Project

Appointment Scheduling System

The Appointment Scheduling System is a reusable web application designed for businesses and professionals. Users can select a service, choose a date, and book an available time slot. Staff can manage availability, confirm or cancel appointments, and review upcoming bookings.


Objectives

  • Provide online appointment booking.
  • Display available services and time slots.
  • Help staff manage appointments and schedules.
  • Reduce manual scheduling and booking conflicts.
  • Store appointment information in a database.

Technologies Used

Frontend: HTML, CSS, JavaScript

Backend: Node.js and Express.js

Database: Supabase PostgreSQL
